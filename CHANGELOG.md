# Changelog

## 1.0.0 - 2026-10-28

### Added

- Short stereo tape delay with 50-200 ms range and 4-point cubic Hermite fractional reads.
- 12 dB/octave low-cut and high-cut filter stack placed only inside the feedback loop.
- tanh tape saturation on the delayed signal with a unity small-signal transfer curve.
- Wow (0.55 Hz) and flutter (6.3 Hz) LFOs that modulate the delay read pointer as a
  proportional tape-speed error.
- Full-height right-side mixer bay with Input, Wet/Dry and Output glass sliders and a
  horizontal stereo output meter with peak hold and dB scale.
- Sleek futuristic studio-hardware UI: brushed gunmetal chassis, flush screwless glass
  overlay with crimson LED edge-glow, pill preset readout, low-profile knurled metal knobs,
  tactile switches, and a live crimson waveform visualizer.
- Ten factory presets, lock-free waveform telemetry, zero-latency bypass, and offline DSP
  plus VST3 host test harnesses.
- Cross-platform GitHub Actions build/release workflow for Windows x64, Linux x64, and
  macOS Universal.
