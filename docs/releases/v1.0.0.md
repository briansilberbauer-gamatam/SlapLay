# SlapLay v1.0.0

**Tape-style slapback delay for guitar — first public release.**

SlapLay is a short, playable slapback delay built around a degraded tape feedback
loop. It is available as a **VST3** plug-in and a **Standalone** application for
Windows x64, Linux x64, and macOS Universal (Apple Silicon + Intel).

## Highlights

- **Short delay line** — 50 to 200 ms with 4-point Catmull-Rom cubic fractional
  interpolation and a smooth 60 ms time glide.
- **Feedback-only tone stack** — 12 dB/octave low cut and high cut inside the
  loop, plus a permanent 12 Hz DC blocker. The first repeat stays open; every
  successive repeat gets darker and thinner.
- **Tape saturation** — a tanh soft clipper on the delayed signal with unity
  small-signal gain, progressive peak compression, and odd-harmonic warmth.
- **Wow & flutter** — 0.55 Hz wow and 6.3 Hz flutter LFOs modulate the delay
  length as a proportional tape-speed error, so longer repeats warble more.
- **Zero latency** — no oversampling, no lookahead, no host timing shift.
- **Ten factory presets** — from *Rockabilly '59* to *Ghost Echo*.

## Interface

A 1180 × 720 resizable studio-hardware panel with a brushed gunmetal chassis,
flush screwless glass overlay, muted crimson LED edge-glow, pill-shaped preset
readout, live crimson waveform display, low-profile knurled metal knobs, and a
full-height right mixer bay with Input, Wet/Dry, and Output sliders above a
horizontal stereo output meter.

Release builds pass the offline DSP suite (fractional-delay accuracy, feedback EQ
response, saturation harmonics, wow/flutter read-pointer swing, echo timing,
maximum-feedback stability, bypass transparency, state round-trips, and mono
processing) and the VST3 host scan/state smoke test on every platform.
